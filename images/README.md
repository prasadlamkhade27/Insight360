## Screenshot Tips

- Use consistent dimensions (1200x800px or larger)
- Capture full feature views including headers and footers
- Highlight key UI elements if needed
- Ensure images are clear and readable
- Use PNG format for best quality
- Add annotations or arrows to highlight features (optional)

## How to Take Screenshots

### Windows
- Use Snipping Tool (Windows key + Shift + S)
- Or use ShareX for more advanced options

### Mac
- Cmd + Shift + 4 for rectangular selection
- Or use third-party tools like CleanShot X

### Linux
- Use Flameshot for easy screenshot tool
- Or built-in GNOME Screenshot

Once you add all images, they'll automatically display in the README.md feature descriptions!
